5 · RAG Document Q&A Bot

Python · Streamlit · sentence-transformers · Claude API

GitHub · Sep 2026

Problem

Answering questions from long PDFs means tedious manual searching — and a generic chatbot can invent facts that aren’t in the document at all.

What I built

A Streamlit app that extracts PDF text with pypdf, splits it into overlapping ~500-word chunks, embeds them locally with sentence-transformers (all-MiniLM-L6-v2), retrieves the top matches by cosine similarity, and sends only those chunks to Claude for the answer.

Result

Answers stay grounded in the document — every response shows the exact source chunks it used — while local embeddings keep it free to run, with no vector database needed at single-document scale.
